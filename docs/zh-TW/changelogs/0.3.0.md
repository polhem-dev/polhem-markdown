# Polhem.Markdown 0.3.0 — 發佈說明

[English](../../en/changelogs/0.3.0.md)

本檔是 [CHANGELOG.zh-TW.md](../../../CHANGELOG.zh-TW.md) 中 `[0.3.0]` 條目的詳細內容。

Blazor 套件新增 `MarkdownEditor`，兩種前端從此都有原始碼編輯器：依檢視器讀取 Markdown 的方式上色，並可與檢視器同步捲動。
兩個編輯器都在文字上方加了類似 HackMD 的工具列，Blazor 編輯器也有了 Avalonia 版原本就有的行號，兩個編輯器的外觀與操作
從此一致。`MarkdownFormat` 新增圖片、表格與分隔線，編輯器也新增標題循環。

沒有任何公開成員被移除或變更。各類應用需要留意的項目：

- **使用 `MarkdownEditor` 的 Avalonia 應用**：編輯器現在顯示工具列，Tab 也不再停在編輯器本身
  （[Avalonia 編輯器顯示工具列](#avalonia-編輯器顯示工具列)、[Tab 不再停在 Avalonia 編輯器本身](#tab-不再停在-avalonia-編輯器本身)）。
- **對 `MarkdownFormat` 做 `switch` 的程式**：[新增三個值](#markdownformat-新增三個值)。
- **設有 Content Security Policy、使用編輯器的 Blazor 應用**：編輯器會載入套件的模組（[Blazor 的 `MarkdownEditor`](#blazor-的-markdowneditor)）。
- **對應 `--pmd-*` 變數的 Blazor 佈景主題**：編輯器有新變數（[Blazor 的 `MarkdownEditor`](#blazor-的-markdowneditor)、[兩個編輯器的工具列](#兩個編輯器的工具列)）。

## 新功能與變更

### Blazor 的 `MarkdownEditor`

`Polhem.Markdown.Blazor` 新增 `MarkdownEditor`，是 Avalonia 編輯器在 Blazor 上的對應元件
（[#51](https://github.com/polhem-dev/polhem-markdown/issues/51)）：

- 文字在原生的 `<textarea>` 中輸入，輸入法、螢幕小鍵盤與螢幕閱讀器的行為與頁面上其他地方相同。顏色由套件的腳本模組
  `polhem-markdown-editor.js` 畫在 textarea 後方的圖層上，元件會自行載入這個模組。
- 為標記、標題、強調、程式碼、連結、URL、raw HTML 與公式上色；程式碼區塊的上色與檢視器相同。打字停下後片刻才重新掃描，
  只送出有變動的區段。
- `Markdown` 與 `MarkdownChanged` 可用 `@bind-Markdown` 繫結。換行字元會依宿主文字原本的寫法傳回。
- 編輯器自己維護復原紀錄（`UndoAsync`、`RedoAsync`、Ctrl+Z、Ctrl+Shift+Z 與 Ctrl+Y，以及瀏覽器的「編輯」選單），
  因為瀏覽器內建的復原紀錄在編輯器自己修改文字後就不可靠。
- `ApplyFormatAsync(MarkdownFormat)` 與快捷鍵（Ctrl，Mac 為 Command，加 B、I、K、E）套用格式。Enter 延續清單，
  Tab 與 Shift+Tab 調整清單項目的層級；在清單以外，Tab 照常把焦點移到下一個元素。
- `IsReadOnly`、`WordWrap`、`FocusAsync`、`SetCaretOffsetAsync`，以及給 textarea 的 `Class` 與其他屬性（例如 `aria-label`）。
- 支援 interactive server、WebAssembly 與 auto 渲染。以靜態方式渲染時，文字唯讀顯示。

樣式表與檢視器共用 `polhem-markdown.css`。編輯器使用 `--pmd-code-font`、`--pmd-link` 與 `--pmd-code-*` 程式碼 token 顏色，
並新增 `--pmd-heading`、`--pmd-marker`、`--pmd-inline-code`、`--pmd-url`、`--pmd-math`、`--pmd-selection` 與 `--pmd-caret`。

**該怎麼做**：設有 Content Security Policy 的頁面必須允許來自自身來源的腳本。沒有這個模組時，textarea 仍能編輯文字，
只是沒有顏色、工具列指令與行號。

### 兩個編輯器的工具列

兩個編輯器都在文字上方顯示工具列（[#57](https://github.com/polhem-dev/polhem-markdown/issues/57)、
[#58](https://github.com/polhem-dev/polhem-markdown/issues/58)）：粗體、斜體、刪除線；標題循環；行內程式碼、程式碼區塊、
引言；項目清單、編號清單、待辦清單；連結、圖片、表格、分隔線；復原與重做。兩個工具列的按鈕、順序與圖示相同。

- `ShowToolbar` 預設為 `true`，設為 `false` 可隱藏。自己排按鈕的宿主從按鈕呼叫 `ApplyFormat(Async)`、`CycleHeading(Async)`、
  `Undo(Async)` 與 `Redo(Async)`。
- `ToolbarLabels`（`Func<MarkdownToolbarItem, string?>`）替換英文標籤；標籤是各按鈕的提示文字與無障礙名稱，回傳 `null`
  則保留英文標籤。提示文字會依平台加上快捷鍵（Ctrl+B 或 ⌘B）。`MarkdownToolbarItem` 是 `Polhem.Markdown` 新增的列舉，
  為各個按鈕命名。
- 點按鈕時，焦點與選取範圍留在文字中。編輯器唯讀時按鈕停用；沒有可復原或重做的步驟時，復原與重做停用。
- Tab 會在工具列停一次；方向鍵、Home 與 End 在按鈕間移動，Escape 回到文字。
- 圖示由本套件自行繪製，沒有加入圖示套件。
- Avalonia：按鈕是宿主佈景主題的 `Button`，`ToolbarBackground` 與 `ToolbarBorderBrush` 設定工具列的外觀。
- Blazor：`--pmd-toolbar-background`、`--pmd-toolbar-border` 與 `--pmd-toolbar-icon` 設定工具列的外觀。編輯器的標記在根元素與
  textarea 之間多了一層 `.pmd-editor-body`。

### Blazor 編輯器的行號

`MarkdownEditor.ShowLineNumbers` 預設為 `true`，與 Avalonia 相同，在行號欄為每一行編號。自動換行的長行只有一個號碼。
`--pmd-line-number` 設定行號顏色。在 130,000 字元、5,000 行的文字中打字，有行號時每鍵約 36 ms，沒有行號時約 26 ms；
幾百行的文字約 1 ms。

### 圖片、表格、分隔線與標題循環

- `MarkdownFormat` 新增 `Image`（`![文字](url)`，並選取網址）、`Table`（兩欄的表格，游標放在第一個表頭儲存格）與
  `HorizontalRule`（`---`）。表格與分隔線插在選取範圍下方，前後若會緊貼文字就補一行空行；再套用一次會再插入一個。
- `MarkdownEditor.CycleHeading()`（Avalonia）與 `CycleHeadingAsync()`（Blazor）讓選取的行依序成為一、二、三級標題，
  再回到一般文字。

### 讓 Blazor 編輯器與檢視器同步

與 Avalonia 自 0.2.0 起的做法相同：

- `MarkdownViewer.ScrollToSourceOffsetAsync(int)`，以及 `FirstVisibleSourceOffset` 搭配 `FirstVisibleSourceOffsetChanged`，
  在原始碼位置與檢視器的捲動位置之間換算。
- `MarkdownViewer.OnSourceRequested` 接收按住 Ctrl 或 Command 的點選，帶有被點選處的原始碼位置
  （`MarkdownSourceRequestedEventArgs`）。
- `MarkdownEditor.ScrollToSourceOffsetAsync(int)`、`FirstVisibleSourceOffset` 與 `FirstVisibleSourceOffsetChanged`
  在編輯器這一側做同樣的事。

## 行為變更

### Avalonia 編輯器顯示工具列

Avalonia 的 `MarkdownEditor` 現在會在文字上方顯示工具列，升級的應用會在編輯器中看到多出的一列。

**該怎麼做**：要維持 0.2 的樣子，把它關掉：

```xml
<md:MarkdownEditor ShowToolbar="False" />
```

### Tab 不再停在 Avalonia 編輯器本身

編輯器本身不再是 Tab 停駐點：Tab 會先到工具列的第一個按鈕，再到文字。`Focus()` 仍會把焦點移到文字；關掉工具列時，
Tab 與以前一樣直接到文字。

### `MarkdownFormat` 新增三個值

`Image`、`Table` 與 `HorizontalRule` 加在最後。用 `switch` 對應每一個 `MarkdownFormat` 的程式（例如對應到自己的按鈕），
會多出三個沒處理到的值。
