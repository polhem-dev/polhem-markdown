# Polhem.Markdown 0.4.1 — 發佈說明

[English](../../en/changelogs/0.4.1.md)

本檔是 [CHANGELOG.zh-TW.md](../../../CHANGELOG.zh-TW.md) 中 `[0.4.1]` 條目的詳細內容。

修正 0.4.0 為兩個檢視器新增的 `IsStreaming`。沒有任何公開成員被新增、移除或變更，不在串流中的文字顯示方式與 0.4.0 相同。三個套件
隨新版號一起發佈；變更在 `Polhem.Markdown`，兩個檢視器都用它來補完串流中的文字。

各類應用程式需要留意的地方：

- **有設定 `IsStreaming` 的應用程式**：回覆中有寫在同一行的顯示數學時，後面的內容現在也會依完成後的樣子顯示
  （[同一行的顯示數學之後的文字會被補完](#同一行的顯示數學之後的文字會被補完)）。

## 變更

### 同一行的顯示數學之後的文字會被補完

設定 `IsStreaming` 時，檢視器會把文字最後一個區塊還沒結束的語法補上，讓回覆依完成後的樣子顯示。在 0.4.0，只要文字中出現寫在同一行的
顯示數學（例如 `$$x = 1$$`），這項處理就會停止：這一行被當成數學區塊的開頭，而這個區塊永遠不會結束，於是文字被視為停在區塊裡，
之後的內容都不會補完。公式後面的連結、圖片、強調或表格標題列會露出原始 Markdown，直到回覆完成。`$$` 獨佔一行的跨行顯示數學不受影響。

現在 `$$` 後面同一行沒有其他文字時，才會開始一個數學區塊，與 Markdig 的解讀相同。同樣地，開頭是三個反引號、後面同一行還有反引號的行
（例如 ```` ```x``` ```` 這樣的程式碼片段）也不再使後面的文字無法補完
（[#94](https://github.com/polhem-dev/polhem-markdown/pull/94)）。
