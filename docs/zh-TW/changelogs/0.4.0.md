# Polhem.Markdown 0.4.0 — 發佈說明

[English](../../en/changelogs/0.4.0.md)

本檔是 [CHANGELOG.zh-TW.md](../../../CHANGELOG.zh-TW.md) 中 `[0.4.0]` 條目的詳細內容。

這一版著重在閱讀：附目錄的 reader 控制項、文件內搜尋、開啟與儲存圖片、在回覆仍在送達時就呈現，以及 Avalonia 檢視器的選取、
複製與螢幕閱讀器支援。每項功能在兩種前端上的行為都相同，只有瀏覽器本身已經做到的部分例外。

沒有任何公開成員被移除或變更。各類應用需要留意的項目：

- **有鍵盤使用者的 Avalonia 應用**：沒有連結的段落不再是 Tab 停駐點，Tab 改為停在連結上
  （[Avalonia 檢視器中 Tab 依序經過連結](#avalonia-檢視器中-tab-依序經過連結)）。
- **自行綁定 Ctrl+F 或 F3 的 Avalonia 應用**：檢視器取得焦點時會自己處理這些按鍵
  （[Avalonia 檢視器處理 Ctrl+F 與 F3](#avalonia-檢視器處理-ctrlf-與-f3)）。
- **對應 `--pmd-*` 變數的 Blazor 佈景主題**：新增四個變數（[Blazor 套件的新 CSS 變數](#blazor-套件的新-css-變數)）。
- **讀取 Avalonia 檢視器選取內容或剪貼簿文字的程式**：複製現在可跨區塊，圖片與公式會轉成文字
  （[跨區塊選取與複製](#跨區塊選取與複製)）。

## 新功能

### `MarkdownReader` 與目錄

兩個套件新增 `MarkdownReader`：包在 viewer 外面的控制項，把 viewer 排在置中的欄位中捲動，並提供目錄
（[#79](https://github.com/polhem-dev/polhem-markdown/issues/79)）：

- 邊緣的細欄為每個標題畫一條短線。指向或點擊細欄時，標題清單會浮在文字上；選取標題會把它捲到頂端，並把焦點移過去。
- `OutlinePinned` 讓清單成為文字旁的側欄，可雙向繫結，宿主可以記住使用者的選擇。`OutlineSide` 決定細欄與清單放在左側或右側。
- 細欄與清單都會標示正在閱讀的章節。
- `TextMaxWidth` 限制文字欄的寬度。`OutlineLabel`、`PinOutlineLabel`、`UnpinOutlineLabel` 可替換英文標籤。
- 對螢幕閱讀器而言，細欄是按鈕，清單是導覽地標（navigation landmark）。

檢視器本身會列出文字中的標題（`Headings`；Avalonia 以 `HeadingsChanged`、Blazor 以 `OnHeadingsChanged` 通知變更），
並能把指定標題捲到畫面頂端（`ScrollToHeading`、`ScrollToHeadingAsync`）。`MarkdownHeading` 提供每個標題的層級、文字、id
與原始碼位置，兩種前端的 id 相同（[#71](https://github.com/polhem-dev/polhem-markdown/issues/71)）。宿主要自己畫目錄時，
可以改用這些 API，不必用 reader。

### 文件內搜尋

在 Avalonia 上按 Ctrl+F（macOS 為 ⌘F）會在檢視器右上角叫出搜尋列
（[#85](https://github.com/polhem-dev/polhem-markdown/issues/85)）。邊打字邊搜尋，並反白所有符合處；Enter 與 F3 前往下一筆，
加上 Shift 則回到上一筆，Escape 關閉搜尋列。符合處位在收合的 `<details>` 區段內時，區段會自動展開。reader 的細欄上有放大鏡
按鈕，是手機與平板上的入口。`FindMatchBrush` 與 `FindCurrentMatchBrush` 決定反白的顏色，`FindBarLabels` 可翻譯搜尋列。

在瀏覽器中，瀏覽器原生的搜尋就能找到檢視器的文字。兩個檢視器另有相同的 API，供自備搜尋框的宿主使用：Avalonia 的
`Find`、`FindNext`、`FindPrevious`、`CloseFind`；Blazor 的 `FindAsync`、`FindNextAsync`、`FindPreviousAsync`、
`ClearFindAsync`；兩邊都有 `FindMatchCount` 與 `CurrentFindMatch`。符合處可以跨越強調與連結，也能以替代文字找到圖片。

### 開啟與儲存圖片

設定 `ZoomImages` 後，點擊圖片或按 Enter 會把圖片以原尺寸蓋在視窗上
（[#72](https://github.com/polhem-dev/polhem-markdown/issues/72)）。滾輪、雙指縮放或 + 與 - 可以縮放，拖曳可以平移，
雙擊在「符合視窗」與「原尺寸」之間切換，Escape 或點擊圖片旁邊則關閉。連結裡的圖片會改為開啟連結。宿主可透過
`ImageActivated`（Avalonia）或 `OnImageActivated`（Blazor）改用自己的方式顯示圖片。

開啟的圖片右上角有工具列，關閉按鈕旁是儲存按鈕（[#88](https://github.com/polhem-dev/polhem-markdown/issues/88)），
儲存的是原始檔：Avalonia 透過存檔對話框，Blazor 則直接下載。圖片的伺服器不允許頁面讀取時，Blazor 檢視器改在新分頁開啟圖片，
由瀏覽器儲存。宿主可透過 `ImageSaveRequested`（Avalonia）或 `OnImageSaveRequested`（Blazor）改用自己的方式儲存。

### 回覆送達中就呈現

兩個檢視器的 `IsStreaming` 告訴檢視器：這段文字是仍在送達的回覆（[#69](https://github.com/polhem-dev/polhem-markdown/issues/69)）。
設定期間，最後一個區塊尚未結束的語法會先補齊或暫不顯示：粗體與行內程式碼會先補上結尾，連結與圖片等網址完整才顯示，
表格等表頭完整才顯示。不再先露出記號、半截網址或一整行管線，然後再跳動。回覆完成時設回 `false`，文字就完全照原樣呈現。

Blazor 檢視器現在只重新渲染文字變更影響到的頂層區塊，與 Avalonia 檢視器原本只重建這些區塊的做法相同：逐步增長的回覆
只渲染最後幾個區塊，編輯只渲染改到的區塊。過去每次變更都會重新渲染整份文字。

### 跨區塊選取與複製

Avalonia 檢視器可以像瀏覽器一樣跨區塊選取文字（[#1](https://github.com/polhem-dev/polhem-markdown/issues/1)）。
拖曳可以從一個段落、清單項目、表格儲存格或程式碼區塊延伸到下一個，到達畫面邊緣時自動捲動；Ctrl+A（⌘A）選取全文，
複製得到依文件順序排列的純文字。圖片複製為替代文字，公式複製為 LaTeX（`$…$`）。

在 Avalonia 12.0 上，圖片或公式之後的文字複製時不再遺失或錯位，三連擊也會選到這類段落的結尾。

### Avalonia 檢視器的螢幕閱讀器支援

Avalonia 檢視器提供給螢幕閱讀器的資訊與 Blazor 檢視器的 HTML 相同（[#70](https://github.com/polhem-dev/polhem-markdown/issues/70)）：
標題與其層級、連結、清單與清單項目、表格、以替代文字命名的圖片，以及具名群組形式的警示、引言與可收合區段。
Blazor 檢視器的警示加上 `role="note"`，與 Avalonia 檢視器的命名一致。

## 行為變更

### Avalonia 檢視器中 Tab 依序經過連結

Tab 現在依文字順序在連結與按鈕之間移動，Enter 開啟連結。沒有連結的段落不再是 Tab 停駐點；點選後仍會取得焦點，以便選取與複製。

**該怎麼做**：除非應用依賴 Tab 走過每一個段落，否則不需處理。

### Avalonia 檢視器處理 Ctrl+F 與 F3

焦點在檢視器內時，Ctrl+F（⌘F）會叫出它的搜尋列，F3 在符合處之間移動；檢視器會把這些按鍵標為已處理，視窗上的按鍵繫結
在這種情況下不會再收到它們。

**該怎麼做**：自備搜尋功能的應用，從自己的搜尋呼叫檢視器的 `Find` API；或在按鍵到達檢視器之前，以 tunnel 階段的處理常式接手。

### Avalonia 檢視器的修正

- 點選連結裡的圖片會開啟該連結。過去點了沒有反應。
- 檢視器把焦點移到標題或註腳時，目標會留在畫面頂端。過去 ScrollViewer 為了讓取得焦點的文字可見會再捲動一次，使目標偏離頂端。
- 在比視窗矮的 ScrollViewer 中往上移到標題或註腳時，目標會捲到畫面頂端。過去目標會停在畫面上方，差距等於兩者的高度差。

### Blazor 套件的新 CSS 變數

| 變數 | 預設值 | 用途 |
|------|--------|------|
| `--pmd-zoom-backdrop` | `rgba(16, 16, 16, 0.9)` | 以原尺寸開啟圖片時的背景 |
| `--pmd-find` | `rgba(255, 213, 0, 0.4)` | 所有符合處的反白 |
| `--pmd-find-current` | `rgba(255, 150, 50, 0.8)` | 目前符合處的反白 |
| `--pmd-outline-bg` | `Canvas` | reader 目錄的背景，必須遮住底下的文字 |

**該怎麼做**：把 `--pmd-*` 變數對應到自己顏色的佈景主題，補上這四個變數。
