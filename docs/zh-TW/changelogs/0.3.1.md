# Polhem.Markdown 0.3.1 — 發佈說明

[English](../../en/changelogs/0.3.1.md)

本檔是 [CHANGELOG.zh-TW.md](../../../CHANGELOG.zh-TW.md) 中 `[0.3.1]` 條目的詳細內容。

`Polhem.Markdown.Blazor` 現在會以 Blazor WebAssembly 應用程式發佈時的方式接受裁剪驗證。沒有任何公開成員被新增、移除或變更，
檢視器與編輯器的外觀和行為與 0.3.0 相同。`Polhem.Markdown` 與 `Polhem.Markdown.Avalonia` 隨新版號一起發佈，本身沒有變更。

各類應用程式需要留意的地方：

- **以 `TrimMode=partial` 裁剪的 Blazor 應用程式**：現在也會裁剪這個套件（[`Polhem.Markdown.Blazor` 標記為可裁剪](#polhemmarkdownblazor-標記為可裁剪)）。

## 變更

### `Polhem.Markdown.Blazor` 標記為可裁剪

本套件標記為支援裁剪與 AOT（`IsAotCompatible`），與 `Polhem.Markdown` 相同，因此每次建置都會執行裁剪與 AOT 分析器。組件現在帶有
可裁剪標記：只裁剪標記為可裁剪組件的應用程式（`TrimMode=partial`）也會裁剪它，0.3.0 時則會整個保留。`TrimMode=full` 的應用程式
原本就會裁剪它。

本 repo 以 `samples/MarkdownGallery.Wasm` 驗證：這是跑在獨立 Blazor WebAssembly 上的 Gallery。Build CI 的 `wasm` job 以
`TrimMode=full` 發佈這個範例，本 repo 的組件或 Markdig 只要有任何裁剪警告，發佈就會失敗
（[#66](https://github.com/polhem-dev/polhem-markdown/pull/66)）。

若您的應用程式在執行時缺少套件需要的東西而被裁剪掉，請開 issue 並附上您的發佈設定。
