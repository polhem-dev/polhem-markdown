# Polhem.Markdown 0.2.1 — 發佈說明

[English](../../en/changelogs/0.2.1.md)

本檔是 [CHANGELOG.zh-TW.md](../../../CHANGELOG.zh-TW.md) 中 `[0.2.1]` 條目的詳細內容。

本版修正 `Polhem.Markdown.Avalonia` 匯出的型別。沒有任何公開成員被新增、移除或變更，檢視器與編輯器的外觀和行為與 0.2.0
相同。`Polhem.Markdown` 與 `Polhem.Markdown.Blazor` 隨新版號一起發佈，本身沒有變更。

## 修正

- `Polhem.Markdown.Avalonia` 0.2.0 匯出了兩個由 Avalonia XAML 編譯器產生的型別：`CompiledAvaloniaXaml.!XamlLoader` 與
  `CompiledAvaloniaXaml.!AvaloniaResources`。凡是含有編譯過 XAML 的組件都會匯出它們，因此會檢查相依套件匯出型別名稱是否衝突的
  使用端，會在自己的組件裡找到同樣的名稱。編輯器的主題現在改由程式碼建立，套件不再含 XAML，也不再匯出這兩個型別，與 0.1.0
  相同（[#48](https://github.com/polhem-dev/polhem-markdown/issues/48)）。
