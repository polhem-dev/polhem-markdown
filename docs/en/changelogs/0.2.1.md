# Polhem.Markdown 0.2.1 — Release Notes

[繁體中文](../../zh-TW/changelogs/0.2.1.md)

This file holds the details behind the `[0.2.1]` entry in [CHANGELOG.md](../../../CHANGELOG.md).

A fix to what `Polhem.Markdown.Avalonia` exports. No public member is added, removed or changed, and the viewers and the
editor look and behave as in 0.2.0. `Polhem.Markdown` and `Polhem.Markdown.Blazor` ship under the new version without
changes of their own.

## Fixes

- `Polhem.Markdown.Avalonia` 0.2.0 exported two types generated by the Avalonia XAML compiler,
  `CompiledAvaloniaXaml.!XamlLoader` and `CompiledAvaloniaXaml.!AvaloniaResources`. Every assembly with compiled XAML
  exports them, so a consumer that checks the exported type names of its dependencies for clashes found the same names
  in its own assembly. The editor's theme is now built in code, the package holds no XAML, and it exports neither type,
  as in 0.1.0 ([#48](https://github.com/polhem-dev/polhem-markdown/issues/48)).
